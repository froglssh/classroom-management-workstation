# 班級經營整合工作站

臺北市麗山高中林獻升老師製作。六項班級工具共用一份學生名冊：幹部與小老師、座位安排、打掃工作、班費收支、園遊會分工、導師評語；首頁另連結「示範檔案」各資料夾內的最新獨立版程式（共 23 項，含成績、評語、升學、生活工具）。

## 上傳 GitHub 並啟用 Pages

1. 建立一個 GitHub 儲存庫。
2. 將**本資料夾裡面的所有內容**放在儲存庫根目錄，讓 `index.html` 直接位於根目錄。不要只上傳 ZIP，也不要再多包一層資料夾。保留 `共享整合版/` 與 `docs/` 的結構。
3. 至儲存庫 **Settings → Pages → Build and deployment**，Source 選 **Deploy from a branch**，Branch 選 **main**，Folder 選 **/(root)**，再按 Save。
4. 等待 GitHub 完成發布，使用 Pages 頁面提供的網址開啟。

這是一套靜態網站，不需要 npm、伺服器端 Python 或建置程序。`index.html` 是首頁；`.nojekyll` 用於停用 Jekyll 處理。部署來源若選其他分支，請改選實際上傳的分支。

GitHub 官方說明：
- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 開始使用

1. 首頁 → 開啟學生資料 → 建立班級與學期。
2. 匯入 Excel 或新增學生 → 儲存共用名冊。
3. 幹部與小老師工具安排職務，或匯入該工具匯出的 JSON，檢查對應後確認。
4. 座位與評語自動讀取共用職務；其他工具共用學生名冊。
5. 定期在資料中心下載「完整備份 JSON」。

## 資料保存與搬移

- **兩層保存**：共用名冊與六項整合版工具即時存於瀏覽器 IndexedDB；首頁「資料保存」可指定資料夾（Chrome／Edge），資料一變動就寫入 `班級經營工作站資料.json`，並在 `班級經營工作站_歷史/` 保留 14 天每日版本。建議選雲端硬碟同步資料夾。
- 資料夾被其他電腦更新時不會直接覆蓋，首頁會請老師選「載入資料夾版本」或「以本機覆蓋」，被取代的一份先存入歷史資料夾。
- 瀏覽器重開後需按一次「重新授權」才能繼續寫入資料夾。首頁也可要求瀏覽器「永久保存」IndexedDB。

- 網頁在雲端，班級資料保存在目前瀏覽器的 IndexedDB。不同電腦、不同瀏覽器、不同網址來源不會自動共享。
- 本機舊版與 GitHub Pages 為不同來源。請先在舊版資料中心下載完整備份，再於雲端版資料中心還原。
- 同一 github.io 網域下的不同專案仍可能共用瀏覽器儲存空間；此程式沿用既有資料庫名稱以維持備份相容。
- 此包只包含程式、套件與說明，不含學生名冊、任職備份、評語草稿或 API 金鑰。請勿將另外匯出的個人資料備份放入公開儲存庫。
- AI 潤飾需自己的服務設定與網路；一般名冊、職務與座位操作不需要呼叫 AI。

## 獨立版更新後同步整合版

幹部（01）、座位（02）、打掃（03）、評語（09）的整合版由獨立版自動產生。獨立版改好後，在本資料夾執行：

```sh
python3 tools/sync_integrated.py --check   # 看哪些需要同步
python3 tools/sync_integrated.py           # 重新產生 共享整合版/roles.html 等
```

同一指令也會把首頁列出的最新獨立版程式、使用說明與班級文件複製到 `獨立程式/`（約 7.6 MB），GitHub Pages 網站上的連結就會開這份副本；本機用啟動器開啟時，仍直接開「示範檔案」裡的原檔。獨立程式更新後，請重新執行並上傳，網站才會是最新版。

獨立版程式內的 `WS` 判斷（`window.Workspace && window.workspaceStorage`）只在工作站中啟用，單獨開啟時行為不變；請保留這些段落。名冊與職務的轉接寫在 `共享整合版/adapter-<工具>.js`。班費（05）與園遊會（06）仍是舊整合方式，尚未納入同步腳本。

## 本機預覽（選用）

Mac 安裝 Python 3 後雙擊 `啟動班級經營工作站.command`。若本資料夾位於「示範檔案」內（同層有 `01幹部設定` 等資料夾），啟動器以上一層為根目錄，開啟 `http://127.0.0.1:8766/班級經營整合工作站/index.html`，首頁的「最新獨立版」連結才開得到；否則開啟 `http://127.0.0.1:8766/index.html`。網址來源不變，既有資料不受影響。舊版啟動器的服務若仍在執行，新啟動器會自動結束它再重開。

也可在本資料夾執行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

再開啟上面的網址（在「示範檔案」資料夾執行則開啟 `/班級經營整合工作站/index.html`）。直接雙擊 HTML 不適合共用資料，會提示使用啟動器。發布到 GitHub Pages 後不必使用這兩個本機啟動檔。

## 內容

- `index.html`：完整首頁。
- `班級經營整合工作站.html`：相容名稱，轉到首頁。
- `共享整合版/`：資料中心、六工具、共用資料庫、各工具整合程式、CSS、套件與授權。
- `共享整合版/tools-catalog.js`：首頁工具目錄（路徑、說明、分類）。程式改名或搬家只要改這個檔案。
- `共享整合版/storage.js`：IndexedDB 偏好設定與指定資料夾長期保存。
- `tools/sync_integrated.py`：由獨立版重新產生整合版，並更新 `獨立程式/`（見上方說明）。
- `獨立程式/`：最新獨立版程式的網站副本，由同步腳本產生，請勿直接修改。
- `docs/`：六項工具操作說明與整合架構說明。
- `檔案清單.json`：打包時間、檔案大小與 SHA-256。
- `班級工作站啟動器.py`、`啟動班級經營工作站.command`：本機預覽用。

第三方套件授權位於 `共享整合版/vendor/`。此包不另行變更原程式及文件的著作權。
