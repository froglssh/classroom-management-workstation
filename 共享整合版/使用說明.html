一次輸入，跨工具使用

開始使用

雲端使用：直接開啟已發布的 GitHub Pages 網址，不需要 Python 或本機啟動器。本機使用：在工作站資料夾雙擊「啟動班級經營工作站.command」（Mac 需 Python 3）。請在同一瀏覽器、同一網址來源使用名冊及各工具。

  1. 在共用名冊與班級學期建立班級，輸入學年、學期。
  2. 新增學生，或貼上／匯入 CSV、Excel（.xlsx／.xls）或學生名冊 JSON，Excel 會自動辨識表頭，可選工作表與修正欄位；預覽後加入表格，再按「儲存共用名冊」。名冊頁的六項工具入口會先儲存編輯中的名冊再開啟。必填座號與姓名，學號選填。
  3. 返回工作站，確認目前班級學期。六項「開啟工具」會使用這個範圍，各分頁頂端會顯示班級。
  4. 在「幹部與小老師」的指派頁安排職務；若有原始程式匯出的 JSON，可至「匯出／匯入」選擇檔案 → 開始匯入 → 檢查學生對應 → 確認匯入並同步。舊檔依座號與姓名對應共用學生，無法對應時請手動選擇；匯入會取代本學期職務，保留任職歷史、共用名冊與既有座位。等待頂端顯示「職務已同步」，開啟座位頁即可自動顯示職務。改派職務不會移動既有座位。
  5. 評語頁由共用名冊選學生，會列出該學期目前與曾任職務。教師勾選並確認表現後加入素材；已寫好的評語不自動改寫。

幹部與座位新版（2026-10-10）

幹部工具已更新為支援手動兼任的版本；勾選隨機優先分配時，會參考幹部與小老師的總工作數，優先分配工作較少的學生，轉出學生不列入抽選。座位工具已更新至最新版介面，整合版直接讀取共用職務，不需再匯入幹部 JSON；也可按「更新共用職務」重新讀取。職務改派不移動座位，個人備註另行保存。

換學期、改名與轉出

建立新學期時選同一班級，選擇承接舊學期在籍名冊，就能沿用學生 ID；新學期不複製職務、座位、班費與評語。更正學生姓名或座號請編輯原列，儲存後現有安排依 ID 更新。學生轉出改在籍狀態，保留任職與帳務歷史；不自動重排既有安排。

已開啟工具分頁固定原班級學期；首頁切換班級後請從首頁重新開啟工具。這可避免正在編輯的帳務或評語被切換到另一班。

儲存與備份

整合版使用 IndexedDB 保存共用資料及各工具工作區；請等工具頂端顯示已儲存再關閉。資料中心可下載完整 JSON 備份及還原，包含任職歷史及已儲存工具資料，不含 API 金鑰。

同一工具同一班級學期同時開兩頁修改，先儲存者保留，另一頁會停止寫入並提示版本衝突。使用「下載本頁救援資料」保留目前資料，再重新載入。救援檔供人工檢視與取回未儲存內容，不能直接當完整備份還原。

資料只在同一瀏覽器、同一網址來源共享。請固定使用工作站網址；不同連接埠、另一瀏覽器或另一台裝置不會自動共用。Excel、PDF、Word 匯出套件與圖示均隨程式附上。AI 潤飾、外部搜尋及 ChatGPT 連結需要網路與使用者自己的服務設定。GitHub Pages 提供網頁，不提供班級資料的跨裝置同步；請在資料中心使用完整備份 JSON 搬移。

原有資料

若直接開啟 HTML，空白檔案模式會轉到本機共用網址；檔案模式若已有名冊，會提供「帶著名冊開啟工作站」。工作站空白時自動帶入；工作站已有資料時先讓您選擇，若選帶入，先下載工作站完整備份。原檔案模式資料仍保留。

本資料夾已包含六項整合工具完整程式與說明，可獨立上傳，不需要原研習資料夾。整合版不會直接讀取或覆蓋舊工具瀏覽器資料。班費可用原有 JSON 還原功能帶入帳務，請核對學生標籤、繳費與收入對帳；未知學生紀錄保留，不憑同名自動合併。資料中心只建立與維護學生名冊，不提供幹部名冊匯入。請在整合版「幹部與小老師」產生與指派職務，指派結果會自動分享給其他工具；已儲存的職務與歷史仍保留。目前尚未提供原六工具所有歷史資料的一鍵遷移。

完整學生個人檔案、自評及家庭聯絡等仍由原學生資料工具管理；本次共用名冊只包含座號、姓名、選填學號及在籍狀態。
