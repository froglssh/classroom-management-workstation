1. 第一次使用

用電腦版 Chrome 或 Edge 開啟 AI智慧輔助升學系統(codex優化).html，會看到歡迎卡，有三個選擇：

  • 直接開始：從「① 基本設定」填起。
  • 先看範例：載入一份未修飾的草稿（共 9 種檔案類型），直接體驗診斷與 AI 提示詞。範例會另外建立一份新檔案，不會蓋掉你寫的內容。
  • 設定資料夾：選一個雲端硬碟資料夾長期保存（見第 8 節）。
內容會自動儲存，不需要按「儲存」。右上角會顯示「✓ 已存本機 時:分」。想立即存檔可按 Ctrl／⌘＋S。

舊版用過的話：第一次開啟新版時，舊版存在瀏覽器裡的資料會自動轉進來，舊資料仍保留不動。

2. 五個步驟

畫面上方（手機在下方）是步驟列，每一步會顯示目前進度：綠色勾表示完成，橘色表示做了一部分。

① 基本設定檔案類型、校系、能力、佐證
② 草稿打字、貼上或上傳
③ 診斷在本機檢查，不傳出資料
④ AI 優化提示詞、AI 回覆、對照
⑤ 匯出完整度檢查、Word 檔

右上角另有「📚 參考資料」（備審各類資料的撰寫重點，可列印）和「⚙️ 設定」。

3. 我的檔案（多份資料）

自傳、讀書計畫、每一份課程學習成果或多元表現，各存成一份「檔案」。按右上角「📂 我的檔案」可以：

  • 新增檔案：先選類型再按「＋ 新增檔案」，申請校系會沿用目前這份，可再修改。
  • 開啟：切換到別份檔案繼續寫。
  • 複製：例如同一份讀書計畫要改投另一個校系，先複製再修改。
  • 備份：下載這一份的備份檔（.json）。
  • 🗑 刪除：刪除後可馬上按「復原」，也會自動留一個還原點。

「① 基本設定」最上面的姓名、班級、座號是你自己的資料，所有檔案共用，會用在匯出的檔名。

4. 草稿與上傳檔案

  • 把 PDF 或 Word（.docx）拖曳到虛線框，或點一下選擇檔案，就會讀出文字放進草稿。舊版 .doc 請先另存成 .docx 或 PDF。
  • 草稿已經有內容時，會問你要「取代草稿」還是「接在後面」。
  • 草稿下方會即時顯示字數、段落數、總分與待修正項目，建議至少 450 字。
  • 上傳 PDF 時會產生「PDF 圖文檢核摘要」（頁數、圖片、可能有表格的頁面、文字偏少或偏密的頁面），這份摘要會保存。
PDF 原檔不會長期保存。「開啟 PDF 原檔檢視」只在這次開啟頁面期間可以用；重新整理或關閉頁面後，請重新上傳 PDF 才能對照原檔。

5. 診斷

左邊是草稿（可以直接修改），右邊是診斷。系統會依「檔案類型」推薦最適合的診斷：

檔案類型建議的診斷
升學自傳自傳優化診斷（黃金開場、STAR、就讀動機、校系客製化、未來計畫）
讀書計畫、未來發展規劃讀書計畫診斷（N-O-P-Q、短中長程、可行性、校系資源）
其他類型第二階段深度分析（完整性、獨特性、關聯性、真實性、策展主軸）

「其他診斷」還有：本機快速診斷、面試準備診斷，上傳過 PDF 時另有「PDF 圖文檢核」。

  • 結果分成卡片：分數條、優先修正（橘色）、追問題（綠色）、下一步行動。
  • 診斷後如果又改了草稿，會提醒「建議重新診斷」。
  • 在草稿裡按 Ctrl／⌘＋Enter 會直接執行建議的診斷。

診斷用關鍵字與規則在你的裝置上計算，不會把內容傳出去；分數只是參考，重點是看「優先修正」的建議。

6. AI 優化

左邊：提示詞

  • 「提示詞任務」會依最近一次診斷預選（例如自傳 → 升學自傳深度優化），可以自己改。
  • 按「產生提示詞」。之後若改了草稿或任務，會提醒提示詞可能過期。
  • 沒有 API Key 也能用：按「ChatGPT／Gemini／Claude」會先複製提示詞再開啟網站，直接貼上即可。

右邊：AI 回覆

  • 有 API Key 時按「⚡ 用 API 產生回覆」，會顯示等待秒數，可以按「取消」；超過 3 分鐘會自動停止。
  • 用外部網站時，把回覆貼到 AI 回覆欄，一樣會保存。
  • 只保留最新一次回覆：產生新回覆前會先問你。
  • 🔍 與草稿對照／採用：右邊先刪掉 AI 的說明文字、只留正文，按「比較」會用紅色（刪除）和綠色（新增）標出差異；確定後按「採用右邊為新草稿」，之後仍可按「復原」。

AI 設定

選 OpenAI 或 Gemini、模型、API Key 和儲存方式。共用電腦請選「暫時儲存」（關閉瀏覽器就清除）。API Key 只存在瀏覽器，不會寫進資料夾或備份檔。遇到高需求或額度問題，可按「改用快速模型」，或改用外部網站。

AI 的建議要逐句確認是否符合自己的真實經驗。不要讓 AI 虛構活動、數據、課程或教授；面試時每一句都要能說明。

7. 匯出

  • 完整度檢查：列出還沒完成的項目（校系、字數、個資、診斷是否過期等），按「前往」會直接跳到要補的地方。
  • AI 使用誠信聲明：校系要求揭露 AI 使用範圍時，先產生草稿，再依自己實際使用情形修改。
  • 下載 Word 檔：可勾選要包含診斷結果、AI 回覆、誠信聲明、AI 提示詞。
  • 備份這份檔案：下載 .json，可在別台裝置的「⚙️ 設定 → 匯入備份」讀回。

8. 儲存與資料夾

位置內容說明
這台裝置的瀏覽器（IndexedDB）全部檔案的文字內容自動儲存；另有每天一份的自動還原點（留 7 天），刪除、匯入、採用 AI 版本等動作前也會各留一份（留 10 份）。
你選的資料夾（Chrome／Edge）升學輔導資料.json、升學輔導資料_歷史/建議選雲端硬碟裡的資料夾。修改 2 秒後寫入；每天留一份歷史檔（留 14 份）。
備份檔（.json）一份或全部檔案手機、iPad、Firefox 無法選資料夾時使用。
  • 設定方式：「⚙️ 設定 → 選擇資料夾」。下次開啟時若瀏覽器要求，請按上方提示列的「重新授權」。
  • 兩台電腦用同一個雲端資料夾時，系統每分鐘會檢查資料夾是否被另一台更新；兩邊都改過時會讓你選擇用哪一份，沒選到的一份不會遺失（會另存成衝突檔或還原點）。
  • PDF 原檔與 API Key 不會存進資料夾。

9. 常見問題

換電腦後資料不見了？

瀏覽器裡的資料只在那台電腦。請在原電腦設定資料夾（雲端硬碟），或下載完整備份，到新電腦再匯入。

PDF 讀不出文字？

可能是掃描成圖片的 PDF，請先做 OCR 或改用 Word 檔。讀取 PDF／Word 需要網路（載入讀取套件）。

API 一直失敗？

錯誤訊息下方會說明可能原因（金鑰、額度、模型名稱、網路）。學校網路可能擋住 API，可改用「複製並開啟」外部網站。

想從頭開始？

「⚙️ 設定 → 清除這台裝置的全部資料」，清除前會留一個還原點。
