班級學生資料管理｜共享整合版

在工作站中開啟時，學生名冊、班級名稱直接來自「共用名冊」；資料存在本班本學期，和幹部、座位、打掃、評語等工具共用同一份名冊。

← 工作站首頁共用名冊／資料中心獨立版完整說明

和獨立版有什麼不同

項目共享整合版（工作站）獨立版
學生名冊來自共用名冊；新增、轉出、改姓名座號請到資料中心自己匯入或新增
班級名稱來自共用名冊（不能在這裡改）側欄輸入
資料存放工作站共用資料庫；長期保存、完整備份在工作站首頁「資料保存」與資料中心設定這台電腦的 IndexedDB＋自選資料夾
自動還原點由工作站完整備份負責每天＋重要動作前自動保存
幹部／小老師「職位工作」上方顯示工作站本學期職務，按「帶入」寫入手動填寫或匯入幹部程式的 JSON

開始使用

  1. 工作站首頁 → 資料中心：建立班級學期並儲存共用名冊。
  2. 回首頁開啟「班級學生資料管理」，學生會自動出現在名冊。
  3. 左側設定「目前學期」（例如高二上），表格就只顯示本學期。
  4. 「📥 匯入」依 ②→⑤ 匯入基本資料、評語、成績、自評、模考（名冊不必再匯入）。
  5. 用「🗂 全班總覽」一次填寫全班的同一個區塊；用「👤 個別學生」看單一學生完整資料。

先前在獨立版建好的資料，可在獨立版「📤 輸出 → 整班備份 JSON」下載，再到這裡「📥 匯入 → 整班備份 JSON」。第一次開啟時會依「座號＋姓名」把學生對應到共用名冊，不在名冊的學生資料保留並提示。

帶入工作站的幹部與小老師

  • 在「幹部與小老師」工具安排好職務後，本工具的「職位工作」區塊上方會顯示這位學生的本學期職務。
  • 按「帶入這位到（本學期）」或「全班帶入」，職務會補進「幹部」「小老師」欄；原本已填的內容不會被刪除，6 秒內可復原。
  • 全班總覽選「二、職位工作」時，工具列也有「全班帶入工作站職務」。

隱私

  • 身分證字號不儲存、不匯入。
  • AI 金鑰只存在這台電腦的瀏覽器，不會寫入工作站資料或備份。AI 潤飾預設先去識別化（姓名改「該生」），送出前會讓你看過內容。
