# 整合架構與資料說明

首頁 `index.html` 連至 `共享整合版/資料中心.html` 與六項完整工具。所有執行程式均位於此資料夾內，使用相對路徑，適用 GitHub Pages 專案子路徑或網站根目錄。

## 共用資料

`core.js` 管理 IndexedDB；`bridge.js` 與 `adapter-*.js` 連接各工具。共用學生採穩定 ID，各班級與學期有獨立名冊、職務、任職歷史與工具資料。跨分頁以 BroadcastChannel 通知更新；同工具版本衝突會停止寫入。

幹部與小老師是正式職務的設定入口。JSON 匯入先對應共用學生，再取代本學期職務；不替換共用名冊。座位自動顯示正式職務，個人備註另存；評語提供目前與曾任職務供教師選用，不自動改寫評語文字。

## 雲端範圍

GitHub Pages 只提供靜態網頁。班級資料儲存在目前瀏覽器，不會上傳 GitHub，也不會自動同步到其他裝置。搬移資料使用完整備份與還原。AI 潤飾由使用者啟用後呼叫選定服務。

## 維護

編輯本包內對應的 HTML、JS 或 CSS，再重新上傳即可。不要刪除 `共享整合版/vendor/`，匯出與畫面套件從此處載入。個別工具說明保留原版操作介紹；共用名冊、職務同步與備份操作以整合版使用說明為準。
